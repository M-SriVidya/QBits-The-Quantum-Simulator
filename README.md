# QBits – The Quantum Simulator

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#license)  
_A Quantum Computing Simulator_

---

## About

QBits is a quantum computing simulator, designed to help users **visualize** and **simulate** basic quantum gates and operations. It includes both backend logic (to represent qubits, gates, and measurement) and a website / graphical component to display results and possibly interact with quantum circuits graphically.

---

## Features

- Supports creation and manipulation of quantum bits (_qubits_)  
- Implementation of standard quantum gates (e.g., Hadamard, Pauli-X, Controlled-NOT, etc.)  
- Measurement of qubit states  
- Visualization via a website interface (images and interactive display)  
- Static assets (images) for illustrating quantum states / circuits
